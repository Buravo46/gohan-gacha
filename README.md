# 🎰 今日のごはんガチャ

**「今日、何食べよう？」を、ボタン1つで決めるWebアプリです。**

朝食・昼食・夕食の料理をあらかじめ登録しておくと、ガチャを回すだけで今日の献立をランダムに決めてくれます。

- インストール不要・ビルド不要（HTML / CSS / JavaScript のみ、外部ライブラリなし）
- スマホのホーム画面に追加して、アプリのように使えます（PWA対応）
- 登録した料理は端末の中だけに保存され、サーバーには送信されません


## 主な機能

### ガチャ
- 朝食・昼食・夕食を **まとめて一括抽選**
- 気に入った食事は **🔒ロック** して、ほかだけ引き直し
- **🔄その食事だけ** 引き直し
- 「朝は食べない」など、食事ごとに **食べる／食べない** を切り替え
- 前回と同じ料理は出にくくなる工夫つき
- 結果のコピー・共有（LINEなどに送れます）
- 最近の献立を5件まで表示

### 料理リスト
- 朝食・昼食・夕食ごとに料理を登録（改行で複数まとめて登録できます）
- 料理名の **編集**・削除
- **参照URL**（レシピページなど）を登録でき、🔗からすぐ開けます

### 設定・その他
- **CSVの書き出し／読み込み**（バックアップ、別のスマホへの引っ越し、Excelでの編集）
- **文字サイズ**：「大きい文字」スイッチで、文字を約30%大きくできます（ご家族・年配の方向け）
- テーマカラー5色
- ダークモード対応（端末の設定に自動で合わせます。設定画面で「ライト／ダーク」を固定することもできます）
- ホーム画面に追加（PWA）・オフライン起動

## 使い方

1. 「料理リスト」タブで、食べたい料理を登録します（最初はサンプル料理が入っています）
2. 「ガチャ」タブで **🎲 ガチャを回す！** を押します
3. 気に入った食事は🔒でロックして、もう一度回すこともできます

### ホーム画面に追加する

| 端末 | 手順 |
|---|---|
| iPhone | Safariで開く → 共有ボタン →「ホーム画面に追加」 |
| Android | Chromeで開く → メニュー →「アプリをインストール」または「ホーム画面に追加」 |

## フォルダ構成

```
.
├── index.html              画面の骨組み
├── css/
│   ├── base.css            配色（CSS変数）・リセット・共通パーツ
│   ├── layout.css          ヘッダー・タブバー・＋ボタン・お知らせ
│   ├── gacha.css           ガチャ画面（食事カード・スイッチ・ボタン・履歴）
│   ├── dishes.css          料理リスト画面・追加/編集シート
│   ├── settings.css        設定画面
│   └── effects.css         紙吹雪・「動きを減らす」設定への対応
├── js/                     ※ index.html に書いた順に読み込まれます
│   ├── config.js           設定値（食事の種類・サンプル料理・テーマ色・履歴の件数）
│   ├── utils.js            便利関数（要素取得・エスケープ・お知らせ表示）
│   ├── state.js            状態と、保存・読み込み（localStorage）
│   ├── theme.js            テーマカラー
│   ├── gacha.js            ガチャ画面（抽選・表示・共有）
│   ├── dishes.js           料理リスト・追加/編集シート
│   ├── csv.js              CSVの書き出し・読み込み
│   └── app.js              タブ切替・起動処理・Service Worker登録
├── manifest.webmanifest    ホーム画面に追加するための設定（PWA）
├── sw.js                   オフライン対応（Service Worker）
└── icons/                  アプリアイコン
```

## カスタマイズ

| 変えたいこと | 場所 |
|---|---|
| サンプル料理・食事名・履歴の件数・テーマ色 | `js/config.js` |
| 色・余白・見た目 | `css/` の該当ファイル（配色は `css/base.css`） |
| 画面の文言・説明 | `index.html` |
| ファイルを追加・名前変更したとき | `index.html` の読み込み、`sw.js` の `FILES` を更新 |

### 更新したのに古い表示のままのとき

オフライン対応のため、一度開いたファイルは端末に保存されています。
`sw.js` の `CACHE` の名前（例：`gohan-gacha-v4`）を `v5` などに変えて再公開すると、入れ替わります。

## データの扱い

- 登録した料理・履歴・テーマは、端末のブラウザ（localStorage）に保存されます
- 外部への送信は一切ありません
- 端末やブラウザをまたいだ自動共有はありません。引っ越しや共有は、設定画面のCSV書き出し／読み込みを使ってください
- ブラウザのデータを消去すると、登録した料理も消えます。大事なデータは、時々CSVで書き出しておくと安心です

### CSVの形式

```csv
食事,料理名,URL
朝食,納豆ご飯,
昼食,カレー,https://example.com/curry
夕食,唐揚げ,
```

- 食事は `朝食` / `昼食` / `夕食` のいずれか
- URLは `http://` または `https://` で始まるもの（空欄でも可）
- 文字コードは UTF-8（Excelで保存したShift_JISも読み込めます）
